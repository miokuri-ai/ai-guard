# 手順6: 会話が切れたあと、再開するとき

なぜ要るか: 長い仕事は1回の会話に収まらない。会話の終わりに書く引き継ぎ(要約)は、まさに「切れかけの」会話が書くので、直前の指示が落ちることがある。原文は、会話の記録(jsonl)に残っている。

## 人間がすること(1分)
1. Ubuntu の画面で、プロジェクトのフォルダに移り、直前の会話の記録から自分の長い発言だけを取り出す
   ```
   cd ~/my-project
   python3 ~/ai-guard/files/extract_user_messages.py --previous --last 10 --min-chars 80
   ```
   (`--previous` は1つ前の会話の記録を自動で探す。Claude Code をまだ起動していなければ `--latest` でもよい)
2. 新しい会話の最初に、引き継ぎと一緒に、この出力を渡す

## 再開するAIに渡す指示文

```
作業を再開します。次の2つを読み、突き合わせてから、次の手を出してください。

1. 引き継ぎ: {掲示板の引き継ぎの置き場所}
2. 直前の会話での、私(人間)の発言(原文): {extract_user_messages.py の出力}

# やること
- 私の発言の中の要求・指示を、1つずつ一覧にする
- それぞれについて、引き継ぎに書かれているか、もう済んだか、まだ手を付けていないか、を書く
- 引き継ぎにあって、私の発言にない「推奨の次の手」は、参考として分けて書く(私の要求の代わりにしない)

一覧を出すまで、新しい作業は始めないでください。
```

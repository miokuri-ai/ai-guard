# 指示文2: 記録を人が読む形にまとめ直させ、別のAIに読ませる

いつ使うか: 何週間・何ヶ月も続いている仕事で、記録(掲示板、教訓メモ、報告の山)が膨らみ、中にいるAIも人間も全体を見渡せなくなったとき。月に1回など、定期的に。

なぜ効くか: 長い運用では、記録・規則・結論が絡まり合い、中にいるAIからは偏りや取りこぼしが見えなくなる。人が読む文章(時期の順、何を試し・何を捨てたか)にまとめ直すと、絡まりがほどけて並ぶ。それを、その仕事に関わっていない別のAIに読ませると、偏りが表に出る。

2段階で使う。段階Aと段階Bは**別の会話**にする。

---

## 段階A: まとめ直させる(仕事をしているAIに)

```
これまでの仕事の経緯を、この仕事を知らない人が読んで分かる文章にまとめてください。
読者は、この分野にもプログラムにも詳しくない人です。専門用語は生活の言葉に置き換えてください。

# 材料
{掲示板・報告・教訓メモ・会話の記録の置き場所と、対象の期間}

# 書き方
- 時期の順に書く
- 「何を試したか」「何が分かったか」「何を捨てたか(やめたか)」「なぜ捨てたか」を、それぞれはっきり書く
- 捨てた判断には、そのとき使った物差し(判定の基準、使ったデータ、条件の絞り方)を書く
- 途中で直したバグや、変えた決まりも、いつ直したかを書く
- 自分たちに都合の悪いことも省かない。分からないことは「分からない」と書く
```

## 段階B: 別のAIに読ませる(この仕事に関わっていないAIに)

```
下の文章は、ある長い仕事の経緯をまとめたものです。あなたはこの仕事に関わっていません。
外から読んで、次のものを探してください。書いた側の説明に合わせる必要はありません。

# 文章
{段階Aの出力}

# 探すもの
1. 疑い方の偏り: 良い結果は疑うのに、悪い結果はそのまま信じている(または逆)ところ
2. 根拠が崩れたのに、見直されていない結論: 途中で直したバグや変えた決まりの「前」に出した結論で、その後に見直した記述がないもの
3. 条件を絞らずに捨てた判断: 全体の平均だけで「効果なし」「無理」としたもの
4. 見直しの道を塞ぐ言葉: 「再検討しない」「閉鎖」「禁止」などで、理由が今も成り立つか分からないもの
5. 同じ失敗の繰り返し: 形を変えて何度も起きている失敗
6. 書いてあることと、やったことの食い違い: 文章の中で矛盾している箇所

# 出してほしいもの
- 見つけたものの一覧(どの段落か、なぜそう見えるか)
- それぞれについて、確かめるために原本(記録)のどこを見ればよいか
- 見つけられなかったものは「なし」と書く。無理に見つけない
```

---

使うときの注意:
- 段階Bで挙がったものは、まだ「疑い」。原本(記録)に戻って確かめてから、手当てする
- 段階Aの文章そのものも、事実と合っているかを人間が確かめる。まとめる途中で、AIがもっともらしく埋めることがある
- 公開する記事として書かせると、読者に伝わるかを意識するぶん、まとめ直しがより丁寧になる(筆者の経験)

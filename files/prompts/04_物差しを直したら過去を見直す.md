# 指示文4: 物差しを直したら、その物差しで出した過去の結論を見直す

いつ使うか: 判定の基準を変えたとき、データの誤り(バグ)を直したとき、評価のやり方を改めたとき。そのたびに必ず。

なぜ要るか: 長い運用では、物差しを直す仕事は「直す仕事」として完了し、その物差しで過去に捨てた候補や出した結論は、誰も見直さない。とくに「効果なし」として捨てたものは、見直しの道が塞がれやすい(「再検討しない」と書いて閉じるため)。

---

```
物差しを直しました。この物差しで過去に出した結論を、洗い出してください。

# 直した物差し
- 何を直したか: {例: 風向きのデータの読み方が誤っていた(向きの反転・角度のずれ)。2026-09-18 に修正}
- 影響する期間・データ・判定: {例: 風向きを使ったすべての判定。修正前に出したもの}

# 対象の記録
{結論や棄却が書かれている記録の置き場所}

# やること
1. 記録の中から、「効果あり」「効果なし」「閉鎖」「採用」「棄却」などの結論を、この物差しを使ったものに限って拾う
2. 1件ずつ、次を書く
   - いつ、何を、どの物差しで判定したか
   - 直した誤りの影響を受けるか(受ける/受けない/分からない)と、その理由
   - 「効果あり」と「効果なし」で、扱いに差をつけていないか(片方だけ割り引いていないか)
   - 見直しを止める言葉(再検討しない・禁止 など)が付いているか
3. 見直す優先度を付ける(高: 誤りの影響を受け、かつ重要な領域/中/低: 今の物差しでも結論が変わらない)

# 出してほしいもの
- 見直し台帳(上の項目の一覧)
- 優先度「高」の件と、それぞれをどう測り直すかの案

測り直しは、まだしないでください。台帳を人間が確かめ、測り直すものを決めてから行います。
```

---

使うときの注意:
- 「無効にする理由」の一覧(例: 当たった回数だけで判定していた時期/全体の平均で判定した/データに誤りがあった時期)を先に作っておくと、毎回の洗い出しが機械的にできる
- 見直した結果、元の判定が正しかったと分かることもある。台帳は「見直しの指示」ではなく、「見直す候補の一覧」として扱う

# 長期運用の点検表

AIに長い仕事を任せている間、定期的に(目安: 毎週の確認と、毎月の確認)当てはめる。「いいえ」が付いた項目は、手引きの該当する章を見る。

## 毎週
| # | 確かめること | はい/いいえ | 手引き |
|---|---|---|---|
| 1 | 今週の「完了」「改善した」の報告のうち、実物(プログラム・ログ・ファイル)を開いて確かめたものはあるか | | 第3章 |
| 2 | 報告の中の数字は、出どころ(ファイル名と行)が書かれているか | | 第3章 |
| 3 | 「確認した」の報告に、確認した範囲と、確認していない範囲が分けて書かれているか | | 第3章 |
| 4 | 会話が切れて再開したとき、直前の自分の発言(原文)と突き合わせたか | | 第6章 |
| 5 | メモリやディスクの事故・止まりが起きていないか。起きたら、原因の特定に根拠(ログ・プロセスの記録)が添えられているか | | 第2章 |

## 毎月
| # | 確かめること | はい/いいえ | 手引き |
|---|---|---|---|
| 6 | 規則・教訓メモの数は、先月より増えていないか。増えたなら、そのうち仕組みにできるものはないか | | 第5章 |
| 7 | 規則は、手を動かす役の定義ファイルに届いているか(指示役の手元だけにないか) | | 第5章 |
| 8 | この1ヶ月で直したバグ・変えた判定の基準について、過去の結論の見直し台帳を作ったか | | 第4章 |
| 9 | 記録を人が読む形にまとめ直させ、仕事に関わっていない別のAIに読ませたか | | 第4章 |
| 10 | 大きな結論(採用・閉鎖)を、別のモデルに監査させたか | | 第3章 |
| 11 | 「効果あり」と「効果なし」で、疑い方に差をつけていないか | | 第4章 |
| 12 | 安全のために道具を絞った役(読むだけの役など)に、その道具で事故になる仕事を頼んでいないか | | 第5章 |

## 新しいモデル・新しい環境に替えたとき
| # | 確かめること | はい/いいえ | 手引き |
|---|---|---|---|
| 13 | 短い試験(付録の台本)で、説明と実際が一致するか、規則を圧力の下でも守るかを確かめたか | | 付録 |
| 14 | 短い試験に合格したことを、長く任せてよい根拠にしていないか | | はじめに |
